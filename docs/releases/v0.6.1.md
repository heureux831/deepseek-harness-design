# Harness Design 0.6.1

在 DeepSeek Harness 右侧栏生成 HTML 原型、点选元素继续修改、保留多份方案、回看修订并并排对比。

这是社区维护的 MIT 开源插件。0.6.1 完善公开分发与文档，Host、浏览器和存储运行代码与 0.6.0 一致。

## 下载与安装

下载本页附件 **deepseek-harness-design-0.6.1.tgz**，无需克隆源码或构建。进入下载目录后：

```sh
# Harness Desktop
npx @deepseek-ai/dsh@0.2.0-rc.2 plugin --profile desktop add ./deepseek-harness-design-0.6.1.tgz

# Harness Web
npx @deepseek-ai/dsh@0.2.0-rc.2 plugin --profile web add ./deepseek-harness-design-0.6.1.tgz
```

需要 Node.js 和 pnpm（推荐 Node.js 24；缺少 pnpm 时可执行 `npm install -g pnpm@11`）。已有 `dsh` 命令可替换 `npx` 前缀。

安装后完全退出并重新打开 Harness，在右侧栏 `+` 中选择 **Design**。Web 用户重启 `npx @deepseek-ai/dsh@0.2.0-rc.2 web`。升级同名包使用同一条安装命令；若仍装有旧 `dsh-design` / `@local/dsh-designer-rN`，先移除其确切包名。同一 profile 只挂载一个 Designer。

## 从第一份原型开始

> 帮我做一个咖啡店首页，方案名叫「暖白咖啡首页」，暖白底色、橄榄绿按钮。请用 Design 预览。

接着打开「点选」、点击目标按钮，再发送修改要求。关闭「点选」可操作原型自己的按钮。另一个设计方向用独立方案保存，点击「对比」查看差异。

## 附件

- `.tgz`：可安装的正式插件包。
- `BUILD.json`：源码提交、tarball SHA-256 和包内文件哈希。
- `SHA256SUMS`：附件校验值。macOS 用 `shasum -a 256 -c SHA256SUMS`；Linux 用 `sha256sum -c SHA256SUMS`。
- `zhihu-publication-kit.zip`：中文介绍文章、发布说明和三张真实面板截图。
