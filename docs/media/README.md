# Public screenshots

These images are captured from a real, isolated DeepSeek Harness Web profile with the Design plugin installed. They use the original static HTML fixtures in `examples/`, not private conversations or unverified model outputs. All examples and screenshots are covered by this repository's MIT license.

- `design-preview.png`: current prototype and compact controls.
- `design-selection.png`: a selected button and its source receipt.
- `design-compare.png`: two named alternatives at phone viewport width.

Reproduce with `DSG_E2E_SHOWCASE=only ./e2e/run.sh <release-tarball>`. Copy the `40-showcase-single.png`, `41-showcase-selection.png`, and `42-showcase-compare.png` artifacts to the corresponding names above. Do not commit browser profiles, launch tokens, logs, or screenshots containing personal session content.
